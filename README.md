# 产业经济学（产业组织理论）教学资料

以「知识创造」为主线组织的产业组织理论课程资料：知识地图、课程大纲、导论课课件、课程主页、生成脚本与提示词。

课程不按教材章节平铺，而是把学科拆成十一条线索，每条线索都按同一条路径展开：从没人回答的问题出发，设定假设，推演结论，放进已知结论中对照，接受批评，再作推广。学生学完每条线索，要能复述这条路径，并能自己走一遍。

**课程主页（GitHub Pages）**：<https://youxuels.github.io/industrial-economics/>

## 知识地图速览

| 编号 | 线索 | 起点问题 | 主导的创造动作 | 来源 |
|---|---|---|---|---|
| 1 | 策略互动 | 少数几家相互牵制，价格和产量停在哪里 | 改一条假设 | 已有 |
| 2 | 结构—行为—绩效 | 集中是否损害绩效，政府能否据此干预 | 创造测量工具 | 已有 |
| 3 | 产品差异与定价 | 去掉同质假设后，企业靠什么竞争 | 更换分析单位 | 已有 |
| 4 | 创新动态 | 市场结构与创新，谁决定谁 | 把静态换成动态 | 已有，补演化部分 |
| 5 | 企业边界与纵向关系 | 为什么会有企业，边界在哪，上下游怎样定价 | 更换分析单位：从市场到交易 | 补充 |
| 6 | 信息 | 信息不对称时市场还存在吗 | 外生变内生：信息 | 补充 |
| 7 | 进入、退出与沉没成本 | 市场结构是给定的，还是竞争的结果 | 外生变内生：结构 | 补充 |
| 8 | 芝加哥批评与反垄断规制 | 凭什么干预，由谁干预 | 批评升级为学派 | 补充 |
| 9 | 经验研究与实验 | 怎样知道理论说的是真的 | 经验反常驱动 | 补充 |
| 10 | 新前沿 | 新现象提出哪些新问题 | 回应新现象、移植工具 | 补充 |
| 11 | 范式之争（暗线） | 主流范式看不到什么 | 换范式 | 补充 |

## 复现

课程大纲：

```bash
python -m pip install python-docx
python scripts/build_syllabus.py
```

课件：见 `slides/README.md`。课件是在线幻灯片（飞书 Slides），构建脚本依赖 `lark-cli` 与对应账号权限；`slides/assets` 里的图片需要先上传换成 `file_token` 才能重新写入。
