# 知识地图与遗漏分析

四条主线能撑起大半门课，但它们有一个共同的默认：研究对象是「同一市场上已经存在的几家企业之间的竞争」。遗漏主要就在这里。

## 一、已有的四条线

| 线 | 起点问题 | 关键节点 | 主导的创造动作 |
|---|---|---|---|
| ① 策略互动 | 少数几家相互牵制，价格和产量停在哪里 | 古诺 1838 → 伯特兰 1883 → 霍特林 1929 → 斯塔克尔伯格 1934 → 纳什 1950 → 进入阻挠、限制性定价、声誉（1980 年代） | 改一条假设 |
| ② 结构—行为—绩效 | 集中是否损害绩效，政府能否据此干预 | Mason 1939、Bain 1951/1956 → 集中度、赫芬达尔指数、勒纳指数等测量 → 经验规律 → 「集中—利润」关系不稳健的批评 | 创造测量工具 |
| ③ 产品差异与定价 | 去掉同质假设后，企业靠什么竞争 | 张伯伦 1933、霍特林 1929 → Lancaster 1966 → Dixit–Stiglitz 1977 → 歧视定价 → 广告 → 转换成本 → 网络效应 → 捆绑 | 更换分析单位（产品换成特征，价格换成价格结构） |
| ④ 创新动态 | 市场结构与创新，谁决定谁 | 熊彼特 1912/1942 → Arrow 1962 → Schmookler 1966 → 专利 → 研发溢出 → Aghion 等 2005 → 兼并重组 | 把静态换成动态 |

整理时有一处调整：张伯伦 1933 放在 ③ 更合适。他和霍特林是「产品差异」的两个源头，在 ① 里只贡献「小集团寡头倾向合谋」一个论点。

## 二、遗漏在哪里

- **企业被当成黑箱**：四条线都只问企业怎么竞争，没问企业为什么存在、边界在哪。
- **结构从哪来、谁来下判断**：② 把结构当作给定，也没写出它后来遇到的对手。
- **怎样知道**：四条线都是理论叙事，测量和检验的方法没有独立成线。
- **④ 缺后半段**：只有创新的激励，没有创新的微观基础和产业的演化。
- **新现象与范式之外的问题**：平台、市场设计、开放经济，以及主流范式看不到的东西。

## 三、补上的线索

| 线 | 起点问题 | 关键节点 | 主导的创造动作 |
|---|---|---|---|
| ⑤ 企业边界与纵向关系 | 为什么会有企业，边界在哪，上下游怎么定价 | Coase 1937 → Spengler 1950（双重加价）→ Williamson 1975 → Grossman–Hart 1986 → 纵向约束 | 换单位：从市场换到交易 |
| ⑥ 信息 | 信息不对称时市场还存在吗 | Stigler 1961（搜寻）→ Akerlof 1970 → Spence 1973（信号）→ Rothschild–Stiglitz 1976（筛选） | 外生变内生：信息成为变量 |
| ⑦ 进入、退出与沉没成本 | 市场结构是给定的，还是竞争的结果 | Bain 1956 → Stigler 1968 → Baumol 等 1982（可竞争市场）→ Sutton 1991（内生沉没成本） | 外生变内生：结构 |
| ⑧ 芝加哥批评与反垄断规制 | 凭什么干预，由谁干预 | Stigler、Demsetz 1973、Posner 1976、Bork 1978 → 规制俘获 1971 → 激励规制（Laffont–Tirole 1993） | 批评升级为学派 |
| ⑨ 经验研究与实验 | 怎样知道理论说的是真的 | 张伯伦的课堂实验 1948 → Smith 1962 → Fouraker–Siegel 1963 → 新经验产业组织 → BLP 需求估计 1995 → 行为产业组织 | 经验反常驱动 |
| ⑩ 新前沿 | 新现象提出哪些新问题 | 双边市场（Rochet–Tirole 2003）→ 拍卖与市场设计 → 相互倾销 1980、战略性贸易政策 1985 → 产业政策 | 回应新现象，移植工具 |
| ⑪ 范式之争（暗线） | 主流范式看不到什么 | 加尔布雷思 1952（抗衡力量）、卡莱茨基的垄断程度、Baran–Sweezy 1966、Eichner 1976（加成定价） | 换范式 |

另外两处延伸：

- **④ 的后半段**：Nelson–Winter 1982（惯例与搜寻）、Gort–Klepper 1982 和 Klepper 1996（产业生命周期）。
- **⑥ 是 ③ 的地基**：二级歧视和广告的分析，都要先有筛选和信息的模型。

⑦ 是 ② 和 ① 之间的桥：在 ① 里进入阻挠是「行为」，在 ② 里集中度是「结构」，⑦ 说明二者是同一件事的两面。

## 四、贯穿全课的知识创造逻辑

古诺那一讲的六个动作（发现空白、设定假设、形式推演、对照定位、接受批判、推广一般化）在每条线上都成立。这张地图又多出五种学科层面的动作：

- **模型层面**：改假设（①）、更换分析单位（③⑤）、把外生变内生（⑥⑦）、把静态换成动态（④）。
- **学科层面**：创造测量工具（②⑨）、回应经验反常和新现象（⑨⑩）。
- **范式层面**：批评升级为学派（⑧）、换范式（⑪）。

每条线都可以让学生填同一张「知识创造卡片」：空白、假设、推演、对照、批评、推广、未解问题。填完十来张，他们看到的就不是一堆模型，而是同一套动作反复出现。

## 五、排课顺序

1. **导论**：从古诺看知识创造。
2. **竞争的行为**：① ③。
3. **结构与绩效**：② ⑦ ⑧，主线是「结构如何被内生、批评如何形成学派」。
4. **企业与信息**：⑤ ⑥。
5. **时间中的产业**：④ 含演化。
6. **怎样知道**：⑨。
7. **前沿与范式**：⑩ ⑪。
