# 提示词 01 · 导论课课件（古诺模型）

## 原始需求

> 讲解古诺模型，从知识生成的角度，让学生学习到知识创造的能力。

## 可直接复用的提示词

```text
讲解古诺模型，但不要只讲结论，要从"知识生成"的角度讲：让学生看见这个模型是怎么被造出来的，
并学会自己造一次。受众是经济学专业本科高年级或研究生，一节课 45 分钟。

要求：
1. 按六个动作组织：发现空白 → 设定假设 → 形式推演 → 对照定位 → 接受批判 → 推广一般化。
   每一步都要说清"这一步在造什么"，而不只是"这一步算了什么"。
2. 推演部分给出完整推导：利润函数、一阶条件、反应函数、均衡解，并用 LaTeX 写公式。
3. 必须与垄断、完全竞争对照（产量、价格、行业利润三行），说明新结论的位置。
4. 必须包含批评与推广：伯特兰 1883 的价格竞争、纳什 1950 的重新命名；
   推广到 n 家厂商与推测变差参数 v。
5. 结尾给一个 25 分钟的小组任务：改一条假设，推出新均衡，并与古诺结果对照。
   参考答案只放在教师备注里，不放在学生页。
6. 输出 14 页课件（在线幻灯片），每页一个观点，含反应曲线图和 n 家厂商曲线图；
   每页备注写 3–5 句可照读的讲稿。
```

## 结构要求（与成品一致）

| 页 | 内容 |
|---|---|
| 1 | 封面 |
| 2 | 六个动作路线图 |
| 3 | 发现空白：垄断与竞争之间的数轴 + 古诺小传 |
| 4 | 设定假设：两眼矿泉 + 五条假设 |
| 5 | 推演一：利润函数 → 反应函数 |
| 6 | 推演二：反应曲线交点 → 均衡解 |
| 7 | 对照：垄断 / 古诺 / 完全竞争 |
| 8 | 批判：伯特兰悖论与后继者 |
| 9 | 推广一：n 家厂商 |
| 10 | 推广二：推测变差 v |
| 11 | 模型的后半生：时间线 |
| 12 | 复盘表：动作 / 古诺做了什么 / 你能做什么 |
| 13 | 课堂任务 |
| 14 | 结语 |

## 设计约束

- 960×540 画布，所有文字 ≥ 18 pt，公式用 LaTeX，不用 Unicode 上下标。
- 底色 `rgb(250,245,240)`，正文 `rgb(46,32,38)`，强调 `rgb(210,90,86)`。
- 不用卡片堆叠和多层套框，用对齐、留白、连线表达关系。
- 图文并茂：封面与假设页用生成插图，人物页用真实肖像，数据页用图表。

## 验收清单
