## 设计规范

- 画布 960×540；所有文字 ≥ 18 pt（教育与科普场景）。
- 底色 `rgb(250,245,240)`，正文墨色 `rgb(46,32,38)`，强调色 `rgb(210,90,86)`，辅助色 `rgb(160,110,105)`。
- 中文微软雅黑；公式一律用 `<formula>` 的 LaTeX，不退化成纯文本或 Unicode 上下标。
- 全稿不用卡片堆叠，用位置、对齐、留白和连线表达关系。

## 构建

依赖：Python 3、飞书 `lark-cli`（已登录且有幻灯片权限）。

```bash
# 1. 上传素材，得到 file_token，写进 gen_slides.py 里的 COVER / SPRINGS / PORTRAIT
# 2. 生成 14 页单页 XML
python gen_slides.py
# 3. 按页序写入（图表页自动走 publish_slide）
python build_all.py
```

- `gen_slides.py`：以函数拼装每页 XML，写 `slide-01.xml`～`slide-14.xml`，同时生成 `references.json`（事实与推导记录）。
- `build_chart.py`：第 6 页反应曲线图、第 9 页 n 家厂商曲线，用图表库生成后合页。
- `build_all.py`：逐页写入，任一页失败即停止。

仓库里的脚本已把飞书 deck ID 与 `file_token` 换成占位符，复现时替换成自己的。
